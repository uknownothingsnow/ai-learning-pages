🤔 什么是 Logit？

神经网络最后一层（全连接层）的原始输出数值，称为 logit。

这些数值可以是任意实数，范围 (−∞, +∞)，没有归一化约束。

❓ 为什么不能直接分类？

  • 数值无法解释为"概率"（可能 <0 或 >1）
  • 多个类别的数值之和不为 1
  • 无法用于损失函数计算
  • 难以量化模型的"置信度"

// 最大 ≠ 直接概率

💡 ArgMax 就是找最大值的下标：
argmax([2.5, 1.0, -0.5]) = 0 // 索引 0 → 猫

✅ ArgMax 的优点

  • 简单直观，计算极快
  • 推理时直接得出类别
  • 不需要归一化

❌ ArgMax 的缺点

  • 输出是离散的 0/1，不可微
  • 梯度处处为 0，无法反向传播
  • 丢失概率信息（无置信度）
  • 不能用于训练！

📐 公式

argmax(z) = i* where
z[i*] = max(z[0], z[1], ..., z[n])
⚠️ 梯度 = 0 ❌
ArgMax 是阶梯函数，导数在切换点不存在，其余处为 0。训练时无法通过梯度下降更新权重。

📐 SoftMax 公式

P(i) = e^(z[i]/T)
       ──────────
       Σ e^(z[j]/T)

T 为温度参数，默认 T=1

✅ SoftMax 的性质

  • 输出范围 (0, 1)
  • 所有概率之和 = 1
  • 保持相对大小顺序
  • 全程可微，支持梯度回传 ✓

🌡️ 温度参数 T

  • T → 0：趋近 ArgMax（概率更尖锐）
  • T = 1：标准 SoftMax
  • T → ∞：均匀分布（熵最大）

🎯 核心结论

  • 训练时用 SoftMax：可导，能计算梯度，权重才能更新
  • 推理时用 ArgMax：快速直接，取最大值即为预测类别

📈 函数对比

  • ArgMax：不连续 不可微
  • SoftMax：连续 处处可微

在实现中，CrossEntropyLoss 通常内置了 SoftMax 计算（log-softmax），数值更稳定，无需手动调用 SoftMax 再传入损失函数。

输入 z →
∂P₀∂P₁∂P₂
← 点击任意格子，在此处显示推导过程

📐 导数公式

// 对角元素 (i == j):
∂P(i)/∂z(i) = P(i)·(1-P(i))

// 非对角 (i ≠ j):
∂P(i)/∂z(j) = -P(i)·P(j)

🔗 链式法则

通过链式法则传播梯度：

∂L/∂z(i) = Σⱼ (∂L/∂P(j))·(∂P(j)/∂z(i))

当与交叉熵结合时，梯度简化为：

∂L/∂z(i) = P(i) - y(i)

（预测概率 − 真实标签，形式优雅）

🎨 颜色含义

  • 绿色 对角线：正导数，值更大时梯度为正
  • 红色 非对角：负导数，抑制其他类别

L = -log(P(correct_class))

L = -(1·log(0.764) + 0·log(0.175) + 0·log(0.061))
  = -log(0.764) ≈ 0.269

✅ 交叉熵的优势

  • 始终为正，且可微
  • 预测越准确，Loss 越小（趋 0）
  • 预测错误时，Loss 急剧增大
  • 与 SoftMax 梯度配合优雅简洁

🎯 训练目标

最小化交叉熵 = 最大化正确类别的预测概率

min L = min(-log P(y*))
⟺ max P(correct_class)

📊 曲线直觉

  • P→1：Loss→0（完美预测）
  • P→0：Loss→∞（完全错误，巨大惩罚）
  • 曲线凸，梯度下降能找到全局最优

🔍 为什么 SoftMax 处处可导？

SoftMax 由指数函数（e^x）和除法组成，两者都是可微的初等函数。

只要分母（归一化项 Σe^z）不为零（指数函数恒正，所以永不为零），SoftMax 对任意输入 z 都有定义且可微。

P(i) = e^z(i) / Σⱼ e^z(j)
分子: e^z(i) — 指数函数，∞ 可微
分母: Σⱼ e^z(j) > 0 — 商法则可用

对比 ArgMax：输出是离散整数，切换点处不连续，导数不存在，非切换处导数为 0。
