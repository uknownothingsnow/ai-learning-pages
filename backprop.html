什么是损失函数？

损失函数 = 衡量"错误"的尺子

模型预测的结果和真实答案之间的差距，就是损失（Loss）。损失越大，模型越差。

以均方误差（MSE）为例：

L(w) = (ŷ − y)2
// 预测值与真实值之差的平方

为什么要最小化损失？

  • 损失曲面形如碗状（凸函数）
  • 碗底 = 最优权重参数
  • 目标：找到让 Loss 最小的 w
本例曲线：
L(w) = (w−1)² + 0.5
// 最小值在 w=1，Loss=0.5

梯度下降

核心公式

w ← w − α · dL/dw

w：当前权重
α：学习率（步长）
dL/dw：梯度（坡度方向）

// 本例：dL/dw = 2(w−1)

学习率的影响

  • α 太小：收敛慢，需很多步
  • α 太大：震荡，越跳越远
  • α 适中：平滑下降，快速收敛

前向传播

计算预测值（蓝色）

输入从左到右流经网络，每一层做线性变换 + 激活函数，最终得到输出值。

x → h = σ(w₁·x) → ŷ = σ(w₂·h)
→ L = (ŷ−y)²
反向传播

计算梯度（红色）

误差从右到左传播，利用链式法则将损失对每个权重的梯度逐层计算出来。

∂L/∂w₂ = ∂L/∂ŷ · ∂ŷ/∂w₂
∂L/∂w₁ = ∂L/∂h · ∂h/∂w₁

为什么需要两个方向？

  • 前向：得到预测，才能知道误差
  • 反向：知道误差如何"怪罪"每个权重
  • 两者结合，才能更新参数

链式法则

∂L/∂w₂ 的展开

∂L/∂w₂ =
  ∂L/∂out ·
  ∂out/∂z₂ ·
  ∂z₂/∂w₂

= 2(out−t) ·
  σ(z₂)·(1−σ(z₂)) ·
  h

∂L/∂w₁ 的展开

∂L/∂w₁ =
  ∂L/∂h ·
  ∂h/∂z₁ ·
  ∂z₁/∂w₁

= (∂L/∂out·∂out/∂z₂·w₂)
  · σ(z₁)·(1−σ(z₁))
  · x

Sigmoid 导数

σ(z) = 1/(1+e−z)
σ′(z) = σ(z)·(1−σ(z))
// 最大值约 0.25（z=0时）

三种梯度下降

Batch GD（全批量）

用全部数据算平均梯度再更新。稳定但慢，内存占用大。

w ← w − α·(1/N)Σᵢ∇L(xᵢ)

Mini-batch GD（推荐✅）

每次用一小批数据（如 32/64 个）算梯度更新，兼顾速度和稳定性。GPU 并行效率高。

w ← w − α·(1/B)Σ_{i∈batch}∇L(xᵢ)

SGD（随机梯度下降）

每次只用1 个样本更新，噪声大，跳出局部最优，但收敛不稳定。

w ← w − α·∇L(xᵢ)
梯度消失

为什么会消失？

Sigmoid 导数最大约 0.25，多层相乘后指数衰减：

∂L/∂w₁ = δ · σ′·σ′·σ′…
≈ δ · 0.25L
// L=10层 → 0.25¹⁰ ≈ 0.000001

ReLU 为什么更好？

ReLU(z) = max(0, z)
ReLU′(z) = 1 (z>0)
// 梯度不会衰减！

梯度为 1，乘以多层后不会缩小，靠近输入层的梯度依然有效。

解决方案

  • 🔀 ReLU / Leaky ReLU 替换 Sigmoid
  • 📊 批归一化 (BatchNorm)：标准化每层输入
  • ➕ 残差连接 (ResNet)：梯度直通公路
  • 🎯 Xavier / He 初始化：合理的权重初始值
  • 📉 梯度裁剪：防止爆炸（clip gradients）
