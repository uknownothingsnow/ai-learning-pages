❓ 为什么需要激活函数？

没有激活函数，无论多少层神经网络，都只是一个线性变换的叠加：

W₃(W₂(W₁x)) = (W₃W₂W₁)x = Wx

激活函数引入非线性，使网络能逼近任意复杂函数（Universal Approximation Theorem）。

💀 梯度消失问题

Sigmoid 导数最大值只有 0.25，在多层网络中每层乘以一个 ≤0.25 的数：

10层后梯度 ≈ 0.25¹⁰ ≈ 0.000001

梯度几乎为零，前面的层几乎无法更新权重！

✅ ReLU 为什么更好？

  • x > 0 时梯度恒为 1，不衰减
  • 计算极简：max(0, x)
  • 稀疏激活：~50% 神经元关闭 → 计算高效
  • 训练更快，默认首选

⚠️ Dead ReLU 问题

若权重更新导致某神经元输入永远为负数，该神经元梯度恒为 0，永远"死亡"。

解法 — Leaky ReLU：

f(x) = x (x > 0) f(x) = αx (x ≤ 0), α = 0.01~0.1

负区间给一个小斜率，保留梯度流动。

🛠️ 实践建议

  • 默认：ReLU（隐藏层）
  • 死亡问题：Leaky ReLU 或 ELU
  • 输出层分类：Sigmoid（二分类）/ Softmax（多分类）
  • 输出层回归：Linear（无激活）
  • 使用 He 初始化配合 ReLU

🔢 矩阵乘法直觉

每个输出神经元 = 所有输入的加权和：

z₁ = w₁₁x₁ + w₁₂x₂ + w₁₃x₃ + b₁ z₂ = w₂₁x₁ + w₂₂x₂ + w₂₃x₃ + b₂

写成矩阵形式：

z = W·x + b [2×1] = [2×3]·[3×1] + [2×1]

📐 维度规则

  • W：形状 [输出神经元数 × 输入维度]
  • x：形状 [输入维度 × 1]
  • b：形状 [输出神经元数 × 1]
  • z：形状 [输出神经元数 × 1]
输入维度 n → 输出维度 m W.shape = (m, n)

💡 为什么向量化？

  • 一次 matmul 替代所有循环
  • BLAS 库、GPU 高度优化
  • 代码简洁：z = W @ x + b
  • 支持 batch（后续步骤）

🚀 为什么用矩阵？

  • 并行计算：矩阵乘法天然并行
  • GPU 加速：CUDA 核心专为矩阵优化
  • Batch 支持：把 N 个样本堆成矩阵，一次算完
  • 自动微分：矩阵形式使反向传播统一

🎒 什么是 Batch？

将 N 个样本堆叠成一个矩阵，一次前向传播同时处理：

单样本: x shape = [n, 1] 批量: X shape = [n, B] ↑ B = batch size

矩阵乘法 W·X 一次得到所有样本的结果。

⚡ 速度提升原理

  • GPU 并行：数千核同时计算不同样本
  • 内存带宽：减少数据搬运次数
  • CUBLAS：高度优化的批矩阵乘法
batch=1: ~1x 速度 batch=32: ~20x 速度 batch=256: ~80x 速度（GPU）

🎯 Batch Size 选择

Batch Size优点缺点
小 (8-32)泛化性好，噪声大→逃脱局部最优慢，GPU 利用率低
中 (64-256)平衡速度与稳定性—
大 (512+)快，梯度稳定泛化差，需调 LR

💾 内存 vs 速度 Trade-off

Batch 越大，显存占用越多。一个 batch 需要存储：

激活值内存 ≈ B × 层激活维度之和 × 4B 反向传播内存 × 2（梯度） 经验值: B=32 时 ~安全
