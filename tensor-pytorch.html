STEP 0 什么是张量（Tensor）？

0D 标量 · Shape: [] · 元素数: 1

🧱 张量是什么？

张量是深度学习的基本数据容器，可以看作是多维数组的推广：

  • 0D（标量）：单个数值，如 loss=0.42
  • 1D（向量）：一组数值，如词嵌入 [512]
  • 2D（矩阵）：表格型数据，如 [batch, features]
  • 3D（图像）：H×W×C，如 [224,224,3]
  • 4D（批量图像）：[N,C,H,W]

📐 Shape（形状）

Shape 描述张量每个维度的大小，是理解张量最重要的概念。

# PyTorch 中的张量 x = torch.tensor(3.14) # [] x = torch.randn(4) # [4] x = torch.randn(3, 3) # [3,3] x = torch.randn(3, 224, 224) # [3,224,224] x = torch.randn(8, 3, 64, 64) # [8,3,64,64]

📡 广播规则

当两个张量形状不同时，PyTorch 会自动广播（扩展）较小的张量：

规则1: 维度不足时在左侧补1 规则2: 大小为1的维度可扩展 [3,1] + [1,3] → [3,3] [1,4] * [3,4] → [3,4] [5,1,3] + [3] → [5,1,3]

🔢 运算类型对比

  • 加法/乘法：逐元素对应位置计算，要求形状相同（或可广播）
  • 矩阵乘法：[m,k] @ [k,n] → [m,n]，内维度必须匹配
A @ B # 矩阵乘法 A * B # 逐元素乘法 torch.matmul(A, B) torch.mm(A, B) # 仅2D

⚠️ 常见形状错误

矩阵乘法时 A 的最后一维必须等于 B 的倒数第二维，否则报错：

✅ [3,4] @ [4,5] → [3,5] ❌ [3,4] @ [3,5] → Error!

🏗️ nn.Module 设计理念

所有 PyTorch 层都继承自 nn.Module，它提供：

  • 自动参数管理（.parameters()）
  • 前向传播接口（forward()）
  • 设备迁移（.to(device)）
  • 保存/加载（state_dict()）

🔀 Sequential vs 自定义

# Sequential：简单堆叠 model = nn.Sequential(...) # 自定义：更灵活 class MyNet(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(3,4) def forward(self, x): return self.fc1(x)

🔄 Autograd 原理

PyTorch 在前向传播时记录所有操作，构建计算图。调用 backward() 时，沿图反向传播梯度。

x = torch.tensor(2.0, requires_grad=True) y = x * x * 3 # y = 3x² z = y + 5 # z = 3x²+5 z.backward() print(x.grad) # dz/dx = 6x = 12

🎯 requires_grad

  • ✔ True：该张量参与梯度计算，典型如模型参数 W, b
  • ✗ False（默认）：输入数据通常不需要梯度
# 关闭梯度（推理时提速） with torch.no_grad(): pred = model(x)

📊 链式法则

Autograd 基于链式法则（Chain Rule）：

∂L/∂x = ∂L/∂z · ∂z/∂y · ∂y/∂x L = (Wx + b - y)² ∂L/∂W = 2(Wx+b-y)·x

❓ 为什么要 zero_grad()?

PyTorch 默认累积梯度（+=）！若不清零，每次 backward 会叠加上一步的梯度，导致参数更新错误。

# ❌ 错误：忘记清零 for x, y in dataloader: loss = criterion(model(x), y) loss.backward() optimizer.step() # 梯度叠加！ # ✅ 正确 optimizer.zero_grad() # ← 必须！ loss.backward() optimizer.step()

🐛 常见训练 Bug

  • Bug 忘记 .zero_grad()
  • Bug 在验证时未关 no_grad()
  • Bug loss 没有调用 .backward()
  • Bug optimizer 更新前没有算 loss
  • Fix 标准顺序：zero→forward→loss→backward→step

🎯 超参数调优建议

  • 学习率：最重要！先用 1e-3，再用 Learning Rate Finder
  • 批次大小：32/64 通常够用，更大需调大 LR
  • 网络深度：先浅后深，加 BatchNorm + Residual

📅 学习率调度器

# 余弦退火 scheduler = CosineAnnealingLR( optimizer, T_max=50) # ReduceOnPlateau（推荐） scheduler = ReduceLROnPlateau( optimizer, patience=5) # 每 epoch 后调用 scheduler.step()

🔧 调优优先级

  1. 学习率（最重要）
  2. 批次大小
  3. 网络架构/深度
  4. 正则化（dropout, weight decay）
  5. 优化器选择
