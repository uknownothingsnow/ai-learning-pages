📉 什么是损失函数？

损失函数（Loss Function）衡量模型预测值与真实值之间的差距。损失越小，模型越好。


训练的目标就是：找到使损失最小的参数 w。


  • 碗的底部 = 最优参数
  • 碗的壁面 = 参数偏离的代价
  • 我们要从碗壁"滚"到碗底

🔢 均方误差（MSE）

// 本教程使用的简化损失：
L(w) = (w − 1)² + 0.3

// 真实场景中的 MSE：
L(w) = 1/n · Σ(ŷᵢ − yᵢ)²

// 最小值在 w* = 1

📐 导数的直觉

导数 = 曲线在某点的切线斜率，告诉我们：


  • 斜率 > 0 → loss 随 w 增大而增大
    → 应该减小 w
  • 斜率 < 0 → loss 随 w 增大而减小
    → 应该增大 w
  • 斜率 = 0 → 到达极值点（最优！）

🔢 导数公式

L(w) = (w−1)² + 0.3

dL/dw = 2(w − 1)

// w = −2：dL/dw = 2(−2−1) = −6
// w = 1：dL/dw = 2( 1−1) = 0
// w = 2.5：dL/dw = 2(2.5−1) = 3

🗺️ 梯度 = 多维导数

当参数从 1 个增加到多个（w₁, w₂, …），导数就变成梯度向量：


∇L = [∂L/∂w₁, ∂L/∂w₂, …]

// 梯度指向损失上升最快的方向
// 我们沿负梯度方向走 → 下降！
学习率 α 0.30
步骤 0
w = −2.00
Loss = 9.30
dL/dw = −6.00

🚶 梯度下降更新规则

w ← w − α · dL/dw

// α = 学习率（步长）
// dL/dw = 梯度（方向）
// 沿梯度反方向移动

🎯 算法流程

  1. 随机初始化参数 w
  2. 计算损失 L(w)
  3. 计算梯度 dL/dw
  4. 更新参数 w ← w − α·grad
  5. 重复 2-4 直到收敛

💡 收敛判据

  • |dL/dw| < ε（梯度接近 0）
  • Loss 变化量 < ε
  • 达到最大迭代次数

蓝色小点 = 历史轨迹，观察下降路径！

🔴 α=0.05 Loss=9.30
🟢 α=0.30 Loss=9.30
🔵 α=1.20 Loss=9.30

⚖️ 学习率的影响

  • 太小 (α=0.05)：每步很小，收敛极慢，需要大量迭代

  • 合适 (α=0.30)：稳定收敛，效率最高

  • 太大 (α=1.20)：步子太大，在最小值两侧来回震荡，甚至发散

📅 学习率调度器

实际训练中，学习率往往不是固定值：


// Step Decay
α(t) = α₀ · γ^(t/step)

// Cosine Annealing
α(t) = α_min + ½(α_max−α_min)
       × (1 + cos(πt/T))

// Warm-up + Decay
先从小学习率预热，再衰减

🗺️ 2D 参数空间

两个参数时，损失面变为三维曲面，我们用等高线热图表示：


L(w₁,w₂) = (w₁−0.5)² + 2(w₂+0.3)²

// 最优解：w₁*=0.5，w₂*=−0.3
// 绿色 × 标记最优点

🔢 偏导数

∂L/∂w₁ = 2(w₁ − 0.5)

∂L/∂w₂ = 4(w₂ + 0.3)

// 梯度向量（指向上升最快）
∇L = [∂L/∂w₁, ∂L/∂w₂]

// 更新规则
w₁ ← w₁ − α·∂L/∂w₁
w₂ ← w₂ − α·∂L/∂w₂

🎨 热图颜色说明

  • 🔵 蓝色区域 = 低损失（接近最优）
  • 🔴 红色区域 = 高损失（远离最优）
  • ⚪ 白色圆点 = 当前参数位置
  • 🔵 蓝色线条 = 下降轨迹
  • ❌ 绿色叉叉 = 最优解位置

💡 Mini-batch 是实践标配

  • 平衡了噪声与计算效率
  • 可利用 GPU 并行加速矩阵运算
  • 带有一定噪声 → 有助于逃离局部最优
  • 实践常用 batch size：32 / 64 / 128

🎛️ Batch Size 建议

// 小 batch（8~32）
更多噪声，正则化效果好
适合小数据集

// 中 batch（64~256）
GPU 利用率高，最常用

// 大 batch（>1024）
需要调大 lr，Linear Scaling Rule:
lr ∝ batch_size
