🌊 顺序数据的挑战

自然界中大量数据都具有时序性——后面的含义依赖前面的内容：

  • 「银行」的含义取决于上下文（金融机构 or 河岸）
  • 股票价格受过去几天走势影响
  • 语音识别需要前后音节配合
普通前馈网络假设输入相互独立，无法捕获这种依赖关系。

🎯 序列模型的应用

🌐 机器翻译 💬 情感分析 📈 时序预测 🎤 语音识别 ✍️ 文本生成 🎵 音乐生成 📰 问答系统 🏥 医疗时序

💡 核心思路

RNN 的关键创新：引入隐状态（Hidden State）hₜ

hₜ = f(hₜ₋₁, xₜ)

每一步的输出不只取决于当前输入 xₜ，还取决于上一步的隐状态 hₜ₋₁，从而携带历史信息。

Step 1：RNN 展开图
将循环展开成时间轴，每步共享同一组参数 W

📐 RNN 计算公式

hₜ = tanh(Wh · hₜ₋₁ + Wx · xₜ + b)
  • xₜ：当前时间步输入（橙色）
  • hₜ₋₁：上一步隐状态（蓝色）
  • hₜ：当前步输出/隐状态（绿色）
  • tanh：激活函数，压缩到 [-1,1]

🔑 参数共享

RNN 最优雅的地方：所有时间步共享同一组参数 Wh、Wx、b

W₀ = W₁ = W₂ = W₃ = W

好处：

  • 参数量固定，与序列长度无关
  • 可处理任意长度的序列
  • 在不同位置学到同一种"处理模式"

🔄 展开的理解

循环结构在时间轴上展开后，等价于一个很深的前馈网络，每层参数相同。

⚠️ 正因如此，反向传播时梯度需要通过所有时间步传递，容易发生梯度消失——这将在 Step 2 详细讲解。
Step 2：RNN 的致命问题 — 梯度消失
反向传播时，梯度随时间步指数衰减，早期词的影响消失殆尽
每个时间步接收到的梯度幅度（越靠左 = 越早期的词）
← t=0（最早） t=T（最晚）→

📉 梯度消失的数学

每经过一个时间步，梯度乘以一个因子 ≤ 1：

∂L/∂h₀ = ∏ᵢ (∂hᵢ/∂hᵢ₋₁) · ∂L/∂hₙ

tanh 的导数最大值为 1，通常 < 1；乘以 T 次后指数衰减。

🤔 为什么 tanh 是罪魁祸首

  • tanh 将输出压缩到 (-1, 1)
  • 饱和区（输入很大或很小）梯度趋近于 0
  • 多步相乘后梯度接近零，早期参数无法更新
  • 网络"记不住"很久以前的信息

💡 LSTM 的动机

我们需要一种机制，让梯度可以"无损"地通过很多时间步传播。

LSTM 的解决方案：引入细胞状态（Cell State）作为"高速公路"，让信息直接流过而不被压缩。

✅ LSTM 用加法更新 Cell State，梯度可以直接流过加法节点！

🧠 Cell State vs Hidden State

Cell State (Cₜ)：长期记忆，高速公路

  • 贯穿整个序列，只有少量线性修改
  • 梯度可以"无阻"地流过，解决梯度消失
  • 类比：人的长期记忆（年份、姓名等）

Hidden State (hₜ)：短期记忆，工作记忆

  • 经过 tanh 压缩，用于当前输出和下一步
  • 类比：人的工作记忆（当前句子上下文）

💡 理解 LSTM 的故事线：
把 LSTM 想象成一个在读长篇小说时记笔记的人：
  1. 遗忘门："上一段的细节不重要了，擦掉" 🗑️
  2. 输入门："这段出现了新的关键人物，记下来" 📝
  3. 输出门："现在要回答问题了，从笔记里找相关内容" 🔍
点击左侧图中的每个门，查看详细公式。

🚪 三个门的核心公式

f = σ(Wf·[h,x]+bf) ← 遗忘门
i = σ(Wi·[h,x]+bi) ← 输入门
C̃ = tanh(Wc·[h,x]+bc) ← 候选
o = σ(Wo·[h,x]+bo) ← 输出门

Cₜ = f⊙Cₜ₋₁ + i⊙C̃
hₜ = o⊙tanh(Cₜ)

σ = sigmoid函数，输出0~1（门控信号）；⊙ = 逐元素相乘

📌 符号说明：[h, x] 表示将两个向量首尾相接拼在一起，变成一个更长的向量（不是相乘）。

📌 直觉理解

想象你在阅读一篇文章，每遇到一个新词：

  • 遗忘门：这个词让你忘了哪些旧知识？
  • 输入门：这个词值得记住多少新信息？
  • 输出门：现在应该输出/表达什么？

💾 长距离依赖的直觉

考虑句子：
「虽然服务很差，但食物很美味」

  • 「虽然」→ LSTM 学会：后面有转折
  • 「差」→ 遗忘门清理正面信息，但"转折标志"保留在 Cell State
  • 「但」→ 激活转折记忆，准备接受正面信息
  • 「美味」→ 输入门大量写入正面情感
  • 最终：正面情感胜出 😊

🆚 与 RNN 的对比

同样的句子，RNN 会：

  • 看到「差」后，正面信息被严重衰减
  • 「但」之前的转折期待难以跨越多步保留
  • 容易误判为负面情感

LSTM 的 Cell State 是"无损高速公路"，使长距离依赖成为可能。

Step 5：RNN vs LSTM vs GRU 对比
三种架构的权衡：简单性 vs 表达力 vs 效率

RNN

最简单的循环网络，一个隐状态

1 状态0 门

LSTM

双状态（C+h），三个门精细控制

2 状态3 门

GRU

LSTM 的简化版，单状态两个门

1 状态2 门

📋 LSTM 详解

  • 参数量：约为 RNN 的 4 倍
  • 训练速度：比 RNN 慢，比 GRU 慢
  • 长期依赖：最强（专为此设计）
  • 适用场景：机器翻译、语音识别、复杂序列建模

📖 GRU（门控循环单元）是 LSTM 的简化版：把遗忘门和输入门合并成一个"更新门"，参数更少、训练更快，效果与 LSTM 相当。本教程不深入讲，了解即可。

🔑 GRU 的简化

GRU（Gated Recurrent Unit，2014）将 LSTM 的遗忘门和输入门合并为更新门，额外增加重置门：

z = σ(Wz·[h,x]) ← 更新门
r = σ(Wr·[h,x]) ← 重置门
h̃ = tanh(W·[r⊙h, x])
hₜ = (1-z)⊙h + z⊙h̃

性能接近 LSTM，参数更少，训练更快。

🚀 选择建议

  • 需要最强记忆：选 LSTM（翻译、长文本）
  • 计算资源有限：选 GRU（移动端、实时系统）
  • 快速原型：选 RNN（简单时序任务）
  • 2024 现状：Transformer 在大部分 NLP 任务上已超越 RNN/LSTM，但 LSTM 在时间序列、低数据场景仍有价值
💡 Mamba (2023) 将 SSM 与选择性状态空间结合，有望在序列建模上再次挑战 Transformer。
