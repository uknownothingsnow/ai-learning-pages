为什么需要嵌入？

🎯 One-hot 的问题

  • 词表大小通常 3万~50万，向量极度稀疏
  • 任意两词余弦相似度为 0，无语义信息
  • 存储和计算代价高昂

✨ 嵌入的优势

  • 将词映射到低维稠密向量空间
  • 相似含义的词，向量距离更近
  • 捕获词法、语法、语义关系
  • 可用于下游任务的特征输入

📐 维度选择

嵌入维度通常在 64 ~ 512 之间：

  • 小模型：64 ~ 128 维
  • 中等模型：256 维
  • 大模型 (BERT/GPT)：768 ~ 4096 维
嵌入矩阵 W ∈ ℝ^(V×d)
V = 词表大小，d = 嵌入维度

🔢 余弦相似度

cos(A,B) = A·B / (|A|·|B|)
取值范围 [-1, 1]，越大越相似

👑 向量类比（最惊人的特性）

king - man + woman ≈ queen

🔍 最近邻搜索

  • 工具：FAISS、Annoy（近似最近邻）

    Skip-gram vs CBOW

    🎯 Skip-gram（当前展示）

    以中心词为输入，预测上下文词。适合低频词，训练数据更多。

    输入: cat → 预测: the, sat

    🔄 CBOW（对比）

    以上下文词为输入，预测中心词。训练速度更快，常用于大词表。

    输入: [the, sat] → 预测: cat

    ⚡ 负采样（Negative Sampling）

    • 原始 Softmax 需计算所有词，代价 O(V)
    • 负采样：每次只更新 k 个"噪声词"
    • 常用 k = 5~20，速度提升 1000×
    Loss = -log σ(v·u_pos) - Σlog σ(-v·u_neg)

    📏 目标函数

    max Σ Σ log P(w_c | w_t)
    t=中心词位置，c=上下文窗口

    Step 4Seq2Seq 编解码网络
    Context Vector 瓶颈

    🏗️ Encoder-Decoder 架构

    • Encoder：逐词读取源语言，最终隐藏状态 → Context Vector
    • Context Vector：压缩整句语义（固定维度瓶颈）
    • Decoder：以 Context Vector 为初始状态，逐词生成目标语言

    🚨 瓶颈问题

    无论句子多长，都要压缩进固定大小的向量！

    • 短句（3词）→ 信息压缩充分 ✅
    • 长句（20词）→ 信息丢失严重 ❌
    • 句子越长，BLEU 分数下降越明显

    💡 解决方案：Attention

    解码每个词时，让 Decoder 直接查看所有 Encoder 隐藏状态，动态加权聚焦相关部分。详见 Step 5。

    h_t = LSTM(x_t, h_{t-1})
    c = h_T # context vector
    y_t = LSTM(y_{t-1}, c) # decode

    Seq2Seq 应用与 Transformer

    🌍 Seq2Seq 的应用

    • 机器翻译（第一大应用）
    • 文本摘要生成
    • 语音识别 ASR
    • 图像描述（Image Captioning）
    • 对话系统 / 问答系统
    • 代码生成（如 Copilot 前身）

    📅 Transformer 取代 RNN 的历史

    • 2014 Seq2Seq + LSTM (Sutskever et al.)
    • 2015 Attention Mechanism (Bahdanau)
    • 2017 Transformer (Vaswani, "Attention is All You Need")
    • 2018 BERT / GPT-1
    • 2020+ GPT-3/4, LLaMA — 纯 Transformer

    🔮 Attention 公式预告

    Attn(Q,K,V) = softmax(QKᵀ/√d) · V
    Q=查询, K=键, V=值
    动态聚焦 → 无瓶颈问题 ✅
